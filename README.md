Bienvenue sur le projet **Pacific Bluffs**, un projet web développé pour le serveur **GTA V RP — FiveM Flashback FA**.

[Pacific Bluffs](https://neast1337.github.io/pacific-bluffs/)

---

## 📋 Présentation

**Pacific Bluffs** est un projet destiné à l'environnement **GTA V RP** du serveur **Flashback FA**.

L'objectif du projet est de proposer une plateforme web permettant de présenter et mettre en valeur **Pacific Bluffs**, avec une interface pensée pour être accessible aussi bien aux joueurs qu'aux personnes souhaitant découvrir le projet.

Le site s'intègre dans l'univers RP du serveur afin de renforcer l'immersion et de fournir une présentation claire et moderne.

---

## 🌴 Pacific Bluffs

Le projet est centré autour de **Pacific Bluffs**, un lieu emblématique de Los Santos pouvant être utilisé dans différents contextes RP.

Le site permet de présenter l'univers du projet à travers une interface web dédiée.

L'objectif est notamment de :

- 🌴 Présenter Pacific Bluffs
- 🏠 Mettre en avant les différents espaces et possibilités
- 🎮 Renforcer l'immersion RP
- 📋 Centraliser les informations utiles
- 💻 Proposer une expérience accessible depuis un navigateur
